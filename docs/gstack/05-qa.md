# 05 QA

## Manual QA Path

1. Run `cargo test --quiet`.
2. Run the CLI on `scenarios/flagship.json`.
3. Run `bash scripts/run_value_benchmark.sh`.
4. Run `bash scripts/run_transient_value_benchmark.sh`.
5. Run `bash scripts/run_power_delivery_benchmark.sh`.
6. Confirm all benchmark result files have `"pass": true`.
7. Generate KB index.
8. Export replay snapshots.
9. Build the site.
10. Run `bash scripts/visual_smoke_test.sh` for quiet route and screenshot proof.
11. Launch the SwiftUI package after copying the Rust binary into resources.

## Visual Checks

- Heatmap is non-empty.
- Workload phase changes the hotspot arrow.
- Cooling lowers peak.
- SRAM spread changes the floorplan and heatmap.
- Explanation panel remains visible and includes assumptions plus non-claims.
- The knowledge page renders generated KB entries from the same markdown source
  used by the app explanation panel.
- The homepage displays the power-delivery proxy section and its benchmark gate.

## Value Benchmark QA

- KV clustered SRAM peak is higher than KV spread SRAM peak in
  `benchmarks/value_loop/results.json`.
- The benchmark summary prints peak reduction, centroid shift, residual, and
  iteration counts.
- The site displays the benchmark JSON result; it does not compute solver
  outputs in the browser.
- The benchmark wording stays framed as usefulness proof for the simplified
  demo, not physical validation.

## Transient Benchmark QA

- Baseline clustered SRAM has measurable time above the demo threshold.
- Spread SRAM reduces the dose metric or moves the hotspot path.
- Workload staggering reduces the dose metric in the bursty trace.
- Stronger cooling has the largest peak reduction in this fixed scenario.
- The site displays the ranking from exported Rust CLI JSON.

## Power Delivery Proxy QA

- Sparse, nominal, and dense bump presets produce ordered worst-droop values.
- Spread SRAM with nominal bumps reduces the simplified droop proxy versus
  clustered SRAM with nominal bumps.
- The benchmark reports thermal/droop hotspot overlap.
- The site displays the proxy metrics from exported Rust CLI JSON.
