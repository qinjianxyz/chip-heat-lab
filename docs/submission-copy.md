## Short Description

Chip Heat Lab is a clean-room open-source demo of engineering simulation for
chip design: a Rust thermal solver, a double-clickable SwiftUI app, and a
Vercel replay that make early floorplan and workload tradeoffs visible.

## Longer Description

Chip Heat Lab demonstrates one narrow workflow: watch a stylized AI accelerator
hotspot move when workload, SRAM placement, and cooling change. The native macOS
app sends scenario JSON to a Rust CLI, which solves a simplified 96x96
steady-state heat model and returns the temperature grid, peak estimate,
hotspot centroid, per-block maximums, residual, and iteration count. The web
site replays exported Rust snapshots and benchmark JSON rather than
reimplementing the solver in the browser.

The value loop is intentionally small and inspectable. For the KV-cache-heavy
scenario, spreading SRAM lowers the simplified peak estimate from `71.085 C` to
`68.236 C` and moves the hotspot centroid by `15.052` grid cells. As a control,
aggressive cooling lowers the training workload peak by `25.076 C`. Those
numbers are generated by `scripts/run_value_benchmark.sh` and checked in under
`benchmarks/value_loop/results.json`.

The newer transient benchmark adds workload memory: prefill, KV decode, IO
flush, and decode tail are stepped through as one trace. It compares spreading
SRAM, stronger cooling, and workload staggering using peak temperature, time
above threshold, thermal dose, spatial gradient, and hotspot travel. That gives
the demo a more realistic design-review loop while keeping the claim boundary
narrow.

GBrain is used as an importable markdown knowledge base for assumptions,
references, demo explanations, and claim boundaries, and the Vercel site exposes
that generated index as a knowledge page. GStack is visible in the repo as
office-hours, scope-lock, engineering review, design review, QA, ship, and
retro artifacts. The point is not to claim a production engineering tool; the
point is to show a useful, honest, end-to-end simulation demo with assumptions,
tests, quiet visual smoke proof, and artifacts that judges can inspect.
